# Kernel studio — итеративное семантическое ядро

Вбиваешь URL. Инструмент снимает **живые формулировки** (подсказки поиска, Вордстат если есть ключ), схлопывает их в **вопросы**, вешает детей на родителей и спрашивает, что брать в ядро.

Не дамп ключей. Пачками. Human-in-the-loop или auto.

```
.venv/bin/python -m kernel serve --open
```

Откроется `http://127.0.0.1:8099/`. Дальше: URL → пачка → «в ядро / не наше / ещё пачка».

CLI без UI:

```
.venv/bin/python -m kernel start --url https://site.ru --brand "Бренд" --gate human
.venv/bin/python -m kernel round --slug brend
```

Состояние: `core/<slug>/kernel.json`.

## Что это не делает

Чужой ВЧ-бренд без ссылок не «взламывает». Auto не берёт `band=high`.

Ключ Вордстата в gitignored `.env`. Частотности идут с Cloud Wordstat (Россия, 30 дней).

Это не `/semantic-core` (тот собирает 36 вопросов под замер open-geo). Это доска контентного ядра: НЧ/СЧ, куда встроиться, страница или H2.

## Политика auto

В ядро сами: S1/S2, не навигация, не ВЧ. Остальное — `deferred`, человек решает.
